# C Programming Course — یادداشت‌ها و تمرین‌های زبان C

این مخزن مستند مسیر یادگیری زبان C است. مطالب از اولین برنامه شروع می‌شوند و تا مباحثی که در کدها و یادداشت‌های این دوره تمرین شده‌اند ادامه پیدا می‌کنند.

هدف این مخزن، نگهداری مثال‌های آموزشی به‌شکل مرتب و قابل مرور در GitHub است؛ هر درس عنوان، توضیح، نکته و مثال مخصوص خودش را دارد.

## ساختار مخزن

```text
C-Learning-Course/
├── README.md
└── main.c
```

تمام مثال‌های این مرحله در `main.c` دسته‌بندی شده‌اند. برای جلوگیری از چندین تابع `main`، هر درس داخل یک تابع مستقل قرار گرفته و از طریق منوی برنامه قابل اجراست.

## کامپایل و اجرا

با GCC:

```bash
gcc -std=c11 -Wall -Wextra -pedantic main.c -o c-course
```

در Linux یا MSYS2:

```bash
./c-course
```

در Windows PowerShell:

```powershell
.\c-course.exe
```

بعد از اجرا، شماره‌ی درس را از منو وارد کنید. گزینه‌ی `0` برنامه را می‌بندد.

## نکات مهم

- برای چاپ اندازه‌ی خروجی `sizeof` از `%zu` استفاده می‌کنیم.
- برای چاپ آدرس حافظه با `%p`، آدرس را به `(void *)` تبدیل می‌کنیم.
- `strcmp` فقط صفر یا غیرصفر بودن نتیجه را برای برابری/نابرابری تضمین می‌کند؛ نباید فرض کنیم نتیجه‌ی نابرابری حتماً `1` است.
- در `scanf` باید اندازه‌ی ورودی رشته با ظرفیت آرایه هماهنگ باشد؛ مثلاً برای `char name[20]` از `%19s` استفاده می‌کنیم.
- `fgets` می‌تواند فاصله‌ها را هم بخواند و در صورت جا شدن، `\n` را نگه می‌دارد.
- آرایه هنگام ارسال به تابع به‌صورت آرگومان، طول خودش را همراه نمی‌برد؛ طول را جداگانه ارسال می‌کنیم.
- در C، آرایه‌ی کاراکتری قابل تغییر است، اما برای جایگزینی کل رشته باید مقصد ظرفیت کافی داشته باشد.
- `fgetc` یک بایت را می‌خواند؛ در فایل UTF-8 تعداد بایت‌ها لزوماً برابر تعداد نویسه‌های قابل مشاهده نیست.
- حالت `w` محتوای قبلی فایل را پاک می‌کند.
- مطالبی مانند حافظه‌ی پویا، `malloc`، `calloc`، `realloc`، `free`، `enum` و `typedef` در فایل ارسالیِ این مرحله به‌صورت درس و مثال کامل ثبت نشده‌اند؛ بنابراین در فهرست درس‌های تکمیل‌شده قرار نگرفته‌اند.
